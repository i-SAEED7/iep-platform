# Project Scope

## الاسم
مبادرة — نحو خطة تربوية فردية رقمية تفاعلية

## الهدف
تحويل الخطة التربوية الفردية من العمل الورقي إلى نظام رقمي تفاعلي لمدرسة واحدة في المرحلة الأولى، مع قابلية التوسع مستقبلًا.

## الأدوار
- Super Admin
- المشرف التربوي
- مدير المدرسة
- المعلم المشرف
- المعلم
- ولي الأمر
- الطالب

## الوحدات الأساسية
1. تسجيل الدخول والحسابات.
2. الجهة التعليمية والبرامج والتسكين.
3. الطلاب والمواد والإسناد.
4. ربط ولي الأمر بالطالب.
5. تحديد المستوى.
6. نقاط القوة والضعف.
7. الخطة التربوية الفردية للمادة.
8. الأهداف طويلة وقصيرة المدى.
9. توزيع المنهج.
10. النموذج التدريسي.
11. فريق البرنامج والتوقيعات.
12. مراجعة المدير.
13. مساحة ولي الأمر.
14. مساحة الطالب.
15. الوكيل التعليمي والأنشطة.
16. الرسائل والخطابات.
17. الطباعة والإشعارات والتدقيق.

## Mobile First
شاشة الجوال هي المرجع الأساسي لجميع قرارات التصميم، ثم تتوسع الواجهة إلى التابلت والكمبيوتر.

## بيانات الإنتاج
لا تستخدم بيانات طلاب حقيقية قبل اكتمال الاستضافة، الصلاحيات، حماية الملفات، النسخ الاحتياطي، التدقيق الأمني، ومراجعة متطلبات الخصوصية.
