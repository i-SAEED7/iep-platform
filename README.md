# IEP Platform
## مبادرة نحو خطة تربوية فردية رقمية تفاعلية

منصة Mobile-First لإدارة الخطة التربوية الفردية رقميًا، مع تحديد مستوى بالوكيل التعليمي، إدارة الأهداف والنماذج التدريسية، ربط ولي الأمر بالطالب، ومساحات مستقلة حسب الدور.

> مهم: لا تُرفع بيانات طلاب حقيقية أو أسرار أو ملفات .env إلى المستودع. التشغيل الحقيقي يتطلب استضافة وقاعدة بيانات وصلاحيات Backend وتدقيق أمني.

### المبدأ المعماري
- حساب شخصي واحد لكل مستخدم.
- صلاحيات Backend وفق: Identity → Permission → Scope.
- المعلم يرى الطلاب المسندين إليه فقط.
- الخطة لكل: طالب + مادة + فصل دراسي.
- الوكيل التعليمي يعمل بوضعين منفصلين:
  - Assessment: مقيّم فقط.
  - Learning: توليد أنشطة ودعم تعلم.
- واجهة عربية RTL وMobile First.

### ترتيب البناء
راجع الملفات داخل `docs/` قبل بدء التنفيذ.
